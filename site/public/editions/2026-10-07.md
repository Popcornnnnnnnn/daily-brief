## Tech & AI

### [Mistral Large 4 enters API preview; weights planned for month-end](https://mistral.ai/news/mistral-large-4/)

**What happened:** Mistral Large 4 entered public preview in Mistral Studio. It is a natively multimodal mixture-of-experts model: only part of its large total parameter set activates per inference. It supports one million tokens of context, visual grounding, coding, and agent workflows. The blog described roughly one trillion total and 49 billion active parameters; technical documentation gave 1.05 trillion and 52 billion, plus a 1.6-billion-parameter vision encoder. **The two official specifications had not been reconciled.**

**Why it matters:** Mistral claimed to outperform some open models on agentic coding tests such as DeepSWE 1.1 and Terminal-Bench 4. These remained vendor evaluations. The release also reflected European labs' pursuit of greater control over models and compute infrastructure.

**Assessment:** Only the hosted API was testable at this stage. Wait for weights, license, model card, and independent evaluations before assessing self-hosting.

### [Anthropic introduces three cybersecurity access tiers](https://www.anthropic.com/news/cyber-verification-program)

**What happened:** Anthropic expanded its Cyber Verification Program into Defense, Red Team, and Specialized tiers for security operations, authorized assessments, and specialist critical-infrastructure work. Available models included Opus 5.5, Sonnet 5.5, and Mythos 5.1. Higher tiers required stricter identity and intended-use checks.

**Why it matters:** Anthropic reported that model-access levels materially affected the scope of professional security tasks. Vendors were beginning to govern capability through identity, access scope, and auditing, rather than relying only on model behavior restrictions.

**Assessment:** Tiering is more flexible than unrestricted access or a blanket ban. Watch credential management, log retention, and isolation between tiers.

### [South Korea proposes roughly $3.5 billion for a national frontier model](https://www.reuters.com/world/asia-pacific/south-korea-plans-develop-35-billion-frontier-ai-model-starting-next-year-2026-10-06/)

**What happened:** South Korea's science ministry told Reuters it planned a roughly KRW 4.7 trillion frontier-model project starting in March 2027. A competitive selection would choose a lead developer, supported by government equity, private capital, chips, data, and talent. Parliamentary budget approval was still needed in December; a lead might be selected in February 2027. This was **a policy proposal, not model training already underway**.

**Why it matters:** Companies, universities, research teams, and project companies could bid. The proposal illustrated centralized national allocation of compute and data, with potential risks of resource concentration or overlapping projects.

**Assessment:** Do not treat the proposed budget as committed investment. Track approval, compute allocation, and eventual openness of the weights.

## Open source & developer tools

### [Claude Code 2.1.290/291 fixes permission boundaries and scheduled-task issues](https://github.com/anthropics/claude-code/releases/tag/v2.1.291)

**What happened:** Version 2.1.290 fixed plan mode potentially auto-approving non-read-only connector tools. It also blocked symlink-based loading of `CLAUDE.md`, rules, and `AGENTS.md` outside the working directory. Other fixes addressed `/loop` tasks disappearing after context compression or executing twice when sessions resumed. Version 2.1.291 then fixed regressions involving lost permission answers in cloud sessions and missing final messages on exit.

**Why it matters:** These changes affect agent permissions and long-task reliability, not just the interface. Permission-system changes can themselves disrupt session state.

**Assessment:** Prefer 2.1.291 when upgrading. Recheck connector approvals, symlinks, and loop tasks in a test repository.

### [Worth studying: OpenHands 1.25.0 adds model routing and per-agent tools](https://github.com/OpenHands/OpenHands/releases/tag/v1.25.0)

**What happened:** OpenHands 1.25.0 can select models based on tasks. Each Agent Profile can choose its own tools from the server catalog, role description, and additional instructions. The release also added cloud automation templates and native Git integration, and fixed possible exposure of local-session secrets through an externally listening address.

**Why it matters:** OpenHands was evolving from a single coding agent into a platform managing models, agent identities, toolsets, and automation. Narrower per-agent tools let a code-review agent operate without also holding deployment or production-system permissions.

**Assessment:** Study routing and Agent Profiles in an isolated environment, focusing on routing cost, Git credential scope, and approval controls.
