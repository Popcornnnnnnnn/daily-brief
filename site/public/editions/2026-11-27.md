## Tech & AI

### OpenAI corrects GPT-6.2 quota accounting

Codex users may reach their plan limits sooner after OpenAI fixed a launch error. OpenAI’s Thibault Sottiaux said last week’s usage was discounted by mistake for most users. He estimated that limits would arrive **40% faster on Astra and 25% faster on Sol** compared with last week. OpenAI also said it would add one banked reset for Go, Plus, Pro, and Business. [Read the announcement](https://x.com/thsottiaux/status/2125784147889393806).

**What to do:** Check your remaining allowance before starting a long run and checkpoint work you need to resume.

### Google gives Workspace agents managed ways to connect

Google’s new Workspace interfaces let outside AI agents work with mail, files, and calendars under administrator controls. The **Model Context Protocol (MCP)** servers connect cloud and web agents, while the command-line tool serves local workflows. Google says technical enforcement for covered external agents begins **February 1, 2027**. [Read the rollout and policy details](https://workspace.google.com/blog/product-announcements/built-for-trust-and-control-new-ai-agent-protections-and-developer-tools-in-google-workspace). *Published Nov 24, 2026.*

**What to do:** Inventory agents using Workspace REST APIs. Identify which actions need scoped sign-in or user confirmation before migrating.

### A shorter machine-checked Riemann proof is available for review

A team working with Claude published a smaller version of an earlier proof that a computer can check. Its compact Lean 4 edition has **about 76,000 lines** and covers the same five theorems as the readable edition, including the generalized result for Dirichlet L-functions. The authors report machine checks and say human mathematicians have yet to read the proof end to end. [Read the repository and its status notes](https://github.com/lsernau/grh-lean/tree/72fead102f663d5c7a407964a13dc0cf9d977207).

**Why it matters:** The readable edition gives reviewers a starting point for checking how the formal statements map to the mathematical claims.

### GitHub will change the default payer for Copilot code review

GitHub’s automated pull request reviews will draw from organization billing in more repositories starting **December 30**. The change applies to eligible Business and Enterprise accounts that have left the payer unset for licensed members. Explicit choices and accounts where paid usage is unavailable follow the exceptions in the [GitHub changelog](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/). *Published Nov 25, 2026.*

**What to do:** Check the current billing choice and choose **Member** before the deadline if you want reviews to use members’ entitlements.

### CISA lists five exploited MiCollab vulnerabilities

MiCollab is Mitel’s calling and conferencing platform. CISA added five MiCollab flaws to its [Known Exploited Vulnerabilities data feed](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json) on Nov 25, including the critical **CVE-2026-133323**. The [Mitel advisory](https://www.mitel.com/support/security-advisories/mitel-product-security-advisory-misa-2026-0012) covers the conferencing component and gives the patch and mitigation. *Catalog entries added Nov 25, 2026.*

**What to do:** Apply Mitel’s patch for **10.3.0.18** or move to a fixed later release. Restrict external access to the affected conferencing component if patching has to wait.

### Multi-agent communication needs a budget-matched baseline

Hugging Face published a [reproducible four-agent training example](https://huggingface.co/blog/training-swarms) using one shared Qwen3-0.6B policy, team rewards, TRL, and vLLM. The authors report that a shorter run reached **60.9% held-out success after about 4.8 hours on two H100s**.

![Hugging Face’s training diagram shows how four agents share a model, receive separate inputs, and exchange messages.](https://huggingface.co/buckets/huggingface/training-swarms-blog-assets/resolve/part-1/task-and-training-loop.png)

The limitation is more important than the headline score: each agent receives private information that the others need, so neither a single agent nor independent retries can solve the task. This experiment shows that a small policy can learn to communicate; it does **not** yet show that communication beats one agent or independent attempts at the same total token budget.

**What to learn:** when evaluating a multi-agent workflow, compare communicating agents with independent retries under a fixed total token budget, and track success, messages, and tokens together. Otherwise, a higher success rate may only mean that the system spent more compute.

## Open source and developer tools

### llama.cpp 1.1.0 adds controls for local models

llama.cpp runs AI models on your own hardware and exposes them through a local server. The [1.1.0 release](https://github.com/ggml-org/llama.cpp/releases/tag/v1.1.0) lets server API callers select a specific tool. It also supports compressing model weights to a target size. The release deprecates the old `llama_batch` C API in favor of `llama_batch_ext`.

Separately, the maintainers published an [AMD benchmark dashboard](https://huggingface.co/blog/ggml-org/llamacpp-amd-bench) with public results for two Radeon configurations. It shows prompt processing and output generation separately, including how throughput changes as context grows.

![The llama.cpp AMD dashboard shows how token generation changes with context length for one model and hardware configuration.](/media/2026-11-27/c53fd10d37df.png)

**What to do:** Test tool selection and batch API changes in staging, then benchmark the models and context lengths you actually use.

### minipg bundles PostgreSQL as a single executable

minipg starts a local PostgreSQL database from one executable and stores it in a `.pgdb` folder. The [project README](https://github.com/progrium/minipg/tree/5dc77aa44a9dbfa6c9ac284a947793533bc30c31) says it embeds the PostgreSQL 18 Alpine image and runs the binaries through a research runtime without requiring Docker. It [appeared on Hacker News](https://news.ycombinator.com/item?id=50650892).

**What to do:** Use it for disposable local tests with data you can recreate. Keep your existing backup and deployment setup for valuable data.

### Side by Side compares three real browser engines in one tab

Side by Side opens the same URL in several desktop browsers so you can compare rendering directly. The [project README](https://github.com/michidk/sidebyside/tree/c0c25fcde52b41d4ba8ad5d29680011aa39760ff) documents Firefox, Chromium, and Epiphany running in separate Linux virtual machines within one tab. Its author recommends **at least 8 GiB of RAM** and says the first launch can take one to three minutes. [See the Show HN launch](https://news.ycombinator.com/item?id=50656036).

![Side by Side showing Firefox, Chromium, and Epiphany in adjacent panes.](https://raw.githubusercontent.com/michidk/sidebyside/c0c25fcde52b41d4ba8ad5d29680011aa39760ff/docs/assets/screenshot.webp)

**What to do:** Reproduce a layout defect across engines, then confirm it on the browser and platform your users actually run.

## Action radar

### GeoServer operators should move to a fixed release

GeoServer publishes map and geographic data services, often on internet-facing endpoints. Canada’s Cyber Centre cites reports that **CVE-2026-120705 and CVE-2026-129243** are being exploited. The [government advisory](https://www.cyber.gc.ca/en/alerts-advisories/geoserver-security-advisory-av26-1207) and [maintainer update](https://geoserver.org/blog/?p=3144) list fixed versions **3.0.2, 2.28.6, and 2.27.7**. *Advisory published Nov 25, 2026.*

**What to do:** Inventory public-facing deployments and update each to its fixed branch. Review relevant access logs if a vulnerable instance was exposed.

### OpenCode 2.4.2 scopes new web-fetch approvals to one site

OpenCode is a coding agent that can fetch web pages during a session. In [version 2.4.2](https://github.com/anomalyco/opencode/releases/tag/v2.4.2), a new **Always allow** choice applies to the site you approved. Previously saved approvals keep their original scope. Scheduled automations also continue to their next run after a failed one.

**What to do:** Review existing web-fetch approvals before relying on the narrower behavior. Replace broad saved rules that the workflow no longer needs.

### Pax lets teams run their own Pydantic agent in the terminal

Pax is a terminal coding assistant built on Pydantic’s beta library for assembling agents. The [launch post](https://pydantic.dev/articles/pax-harness-beta) explains how plugins supply coding tools and sandboxing. With `--agent`, Pax loads your own agent with its tools and instructions and skips the default plugins. [Version 0.75.0](https://pypi.org/project/pydantic-ai-pax/0.75.0/) is available on PyPI. *Published Nov 25, 2026.*

![Pydantic’s diagram compares what loads in standard Pax and in a session started with --agent.](/media/2026-11-27/01cad1ab5656.png)

![Pydantic’s /plugins screen shows which features are on and what the coder plugin provides.](/media/2026-11-27/cd3daaad2d98.png)

**What to do:** Run a small, read-only task with your existing agent. Compare the tools and permissions you see in the terminal with those your service uses.
