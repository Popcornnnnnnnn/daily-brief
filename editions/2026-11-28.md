## Tech & AI

### Hugging Face gets a 10-second video down to 22–23 seconds on Trainium3

Hugging Face tested LTX-2.5, a model that generates video and sound together, on Amazon’s AI chips. Its [engineering write-up](https://huggingface.co/blog/video-trainium3) reports **22–23 seconds for a 2048 × 1024 clip** on 32 NeuronCores, with the model already loaded. The first working run took 5 minutes 20 seconds at lower resolution on four cores.

The team split the clip across chips and moved video decoding from the CPU to the accelerators. Changing the hardware allocation as well as the software makes this a result for the whole setup.

![Hugging Face split the clip into eight stretches, with four accelerator cores per stretch.](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/video-trainium3/parallelism-layout.svg)

**Why it matters:** Compare cost per finished clip and measure cold starts separately when choosing hardware for a video pipeline.

### Moonshot opens applications for Kimi research credits

Moonshot AI’s Kimi for Science program offers researchers credits to call its AI models from software. [The program page](https://www.kimi.ai/news/kimi-for-science-program) lists up to **US$20,000 in model-usage credits** for selected projects, with awards based on need and review. First-round applications close **December 8**. The page [was shared on Hacker News on Nov 27](https://news.ycombinator.com/item?id=50665920).

**What to do:** If your team applies, describe the task, the data you can share, and how you’ll verify the results.

### Claude can install an artifact as a desktop app

An artifact is an interactive tool built in a Claude chat, such as a calculator or timer. Anthropic’s [beta for Mac and Windows](https://claude.com/resources/articles/install-as-app) gives it a separate window and icon. Opening the app still requires an internet connection and a Claude sign-in. *Published Nov 24, 2026.*

The [permission guide](https://support.claude.com/en/articles/18516354-install-an-artifact-as-an-app) distinguishes browser-level access, specific desktop features, and **full computer access**. Each artifact update prompts for permission again. Code loaded from another website can change without a new prompt.

**What to do:** Try a small calculator under default permissions. For a shared app, review where its code loads from before granting desktop access.

### NVIDIA shares training data for extracting tables and charts

Nemotron 3.5 Parse converts images of documents into structured text and data while tracking where each item appeared. NVIDIA’s [release write-up](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin) shares **training data for charts, tables, and multilingual pages**, plus a fine-tuning recipe. *Published Nov 26, 2026.*

![NVIDIA’s synthetic example pairs marked regions on the page with the model’s extracted headings, tables, and chart values.](https://huggingface.co/datasets/nvidia/Nemotron-Parse-Blog-Assets/resolve/main/images/figure-01-page-structure.png)

**Why it matters:** Text can look correct even when a value lands under the wrong column. Check row and column alignment separately on your own forms.

## Open source and developer tools

### Ladybird adds memory controls in its rolling alpha

Ladybird is an independent web browser with its own engine for rendering pages. The [Nov 26 alpha update](https://github.com/LadybirdBrowser/ladybird/releases/tag/2026.48.0) can **unload idle background tabs** and lets you choose how tabs share processes. It also ships Linux AppImage packages. The [initial alpha announcement](https://ladybird.org/posts/alpha/) describes WebDriver support for automated browser tests. *Alpha launched Nov 23, 2026.*

**What to do:** Run one critical website flow on a test profile and report any reproducible compatibility issue.

### SimDrop gives Finder access to running iOS simulators

SimDrop puts running iOS simulators in the Finder sidebar so you can drag files between them and your Mac. The [project README](https://github.com/rxliuli/sim-drop/tree/6f9c68bcefd3804ea756cb1858b92c236aad2bb2) documents separate folders for the simulator’s photo library and Downloads. It requires **macOS 15 or later** and uses a background helper that runs outside the app sandbox. *Shown on Hacker News Nov 26, 2026.* [Author’s Show HN post](https://news.ycombinator.com/item?id=50657070)

![The project’s Finder screenshot shows the Photos and Videos folder for a running simulator.](https://raw.githubusercontent.com/rxliuli/sim-drop/6f9c68bcefd3804ea756cb1858b92c236aad2bb2/Design/screenshot.png)

**What to do:** Start with disposable test files. Hold Option when dragging them in to keep the originals on your Mac.

## Action radar

### Drupal operators should patch and check for compromise

Drupal is a web publishing system whose core installer has an actively exploited access flaw. The U.S. Cybersecurity and Infrastructure Security Agency added **CVE-2026-136716** to its [exploited-vulnerability catalog](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json) on Nov 27. [Canada’s updated advisory](https://www.cyber.gc.ca/en/alerts-advisories/drupal-security-advisory-av26-1209) lists the fixed releases as **10.6.23, 11.3.23, and 11.4.14**.

**What to do:** Upgrade to the fixed version for your branch and restrict public access to the installer. If it was exposed, follow [Drupal’s incident checklist](https://www.drupal.org/docs/administering-a-drupal-site/security-in-drupal/checking-whether-your-site-was-compromised-through-the-installer).

### Copilot CLI separates connector approvals from built-in permissions

GitHub Copilot CLI is a terminal coding agent that can use tools from outside servers. It connects to them through the Model Context Protocol (MCP). In [stable version 1.0.117](https://github.com/github/copilot-cli/releases/tag/v1.0.117), approval for an MCP server **stays scoped to its tools**, including after resume. This holds even when its name matches a built-in permission.

The same release confirms the earlier preview clarification. **Non-interactive runs require prior approval to start an extension**, while interactive autopilot now asks before launching each one.

**What to do:** Test a resumed run and a non-interactive run with the same narrow approvals you use in production.

### Pi keeps tool restrictions when a terminal restores a session

Pi is a coding agent that runs in your terminal and can restart an earlier session. [Version 1.7.0](https://github.com/earendil-works/pi/releases/tag/v1.7.0) lets compatible terminals restore a session with its **original profile, tool restrictions, and instructions**. The [terminal setup guide](https://github.com/earendil-works/pi/blob/v1.7.0/packages/coding-agent/docs/terminal-setup.md#program-resume) explains how the terminal handles trust for each combination of launch flags.

**What to do:** Restart a scratch session with a restricted tool list. Confirm that the restored session still has the intended tools before enabling automatic restore.

### Catch-up: Pax makes a coding agent a replaceable plugin stack

Pydantic released Pax and moved the Pydantic AI Harness into [public beta](https://pydantic.dev/articles/pax-harness-beta) on Nov 25. The Harness exposes more than 100 composable capabilities—including workspaces, memory, subagents, context management, model fallback, and code mode—while Pax is a terminal coding agent built from the same pieces. Its coding agent, sandbox integration, MCP support, and observability are plugins, and it can load a custom Pydantic AI agent instead of the default one.

**Why it matters:** This is a useful system to study if you want to test one harness component without replacing the whole agent workflow. It is still a beta, and Pydantic says the API may change before 1.0. More importantly, the [Pax documentation](https://pydantic.dev/docs/ai/pax/) says it edits files and runs commands as your account with **no sandbox or approval step by default**.

**What to try:** Use a disposable repository and one representative task. Compare completion, tool calls, cost, and permission behavior with your current coding agent before considering a broader workflow change.
