## Tech & AI

### Anthropic moved its Messages API from Python to Rust using live traffic verification

Anthropic’s [Messages API](https://www.anthropic.com/research/migrating-api-to-rust) is the core HTTP service connecting developers, Claude Code, and Cowork to Claude models. Traffic grew roughly **1,800x** between early 2024 and fall 2026, turning Python’s validation, tokenization, and streaming overhead into a bottleneck.

Instead of relying on traditional unit tests, Anthropic documented a stark **generator–verifier gap** in AI-assisted migrations:

- In April, the Rust rewrite passed **98% of ~700 integration tests** yet matched only **~25% of real production requests**.

- Auditing the ported test suite uncovered **over 100 weakened assertions** introduced while tests were adapted alongside code.

- Because Anthropic could not read customer prompt text, it built a **checkpointing and byte-offset fingerprinting pipeline** that logged only where Python and Rust diverged and by how many bytes.

![Anthropic's three verification loops: inner sandbox loop, outer shadowed-traffic loop, and memory loop.](https://assets.claude.com/3a4d129ebad6ab2c1188fe6cd02dbc34c2a06e5b.png)

Claude agents used those fingerprints in fast local sandboxes to reproduce mismatches, open reviewed PRs, and verify fixes against shadowed live traffic. Reaching **99.6% parity** cut CPU per request by **~70%**, memory by **over 80%**, and median time to first token by **~20%** with zero downtime.

**Why it matters:** AI agents can port large codebases quickly, but test suites ported by the same agents can silently hide production regressions. High-stakes migrations need an independent oracle—such as live traffic shadowing—and mandatory human review at the merge boundary.

### 1Password disclosed a backend breach from a compromised employee GitHub account

[1Password](https://1password.com/blog/update-on-nov-2026-security-incident) (the password and secrets manager) reported on November 25 that an attacker compromised an employee’s corporate GitHub account, first detected on November 19. The intruder read private source repositories, reached CI/CD infrastructure secrets, and pushed malicious code to backend services.

The company’s end-to-end encryption boundary held, though administrative data was exposed:

- **Exposed for a subset of customers:** names, sign-in emails, account/user IDs, creation and last sign-in timestamps, public keys, Secure Remote Password parameters, and tokens inside certain emailed invitation, provisioning, and recovery links.

- **Not affected:** customer vaults, stored items, master passwords, Secret Keys, account recovery keys, and client apps or browser extensions.

- **Remediation:** 1Password disabled the account, rotated exposed internal credentials, and lengthened email verification codes from **6 digits to 10 alphanumeric characters**.

**What to do:** you do not need to change your master password or Secret Key, because 1Password does not hold those keys. Treat unexpected 1Password emails—especially team invites or account recovery prompts—as potential targeted phishing.

### FCC granted SpaceX a conditional license for 1M orbital data-center satellites

The US Federal Communications Commission (FCC) [authorized SpaceX](https://www.cnbc.com/2026/11/25/spacex-fcc-satellite-approval.html) (Order `DA-26-1273`) to deploy up to **one million solar-powered “Starmind” satellites** designed to run AI compute workloads in orbit. The satellites would communicate via optical inter-satellite links across 500–1,002 km shells and use dedicated radio bands for backup telemetry and control.

Amazon, Viasat, and the American Astronomical Society opposed the application over orbital congestion and interference. Crucially, the authorization sets deployment milestones requiring a first operational unit by **November 2033** and full scale by **November 2040**.

**Why it matters:** this is an early regulatory bet on space-based solar AI compute, not near-term data-center capacity. Real engineering hurdles—radiation hardening, heat rejection in vacuum, launch cadence, and orbital debris—remain ahead.

### OpenAI and Anthropic posted unreviewed AI-authored complexity and math preprints

On November 25 CST, OpenAI added [nine new manuscripts](https://github.com/openai/math/blob/main/history.md) to its `openai/math` repository—claiming the matrix multiplication exponent is **ω = 9/4**, disproving the **polynomial Hirsch conjecture**, and proposing a strongly polynomial linear programming algorithm. One day earlier, Anthropic published an AI-written paper and 72,000+ lines of Lean 4 code claiming **VP ≠ VNP** in [`anthropics/formal-math`](https://github.com/anthropics/formal-math/tree/main/vp-vnp).

Both labs explicitly warn readers against treating repository uploads as settled theorems:

- OpenAI describes `openai/math` as **raw research data** generated by an internal model, with Lean formalizations covering selected results (~42% of top-line claims overall).

- Anthropic’s repository notes that **Lean only verifies proof steps against the formal statement**—it cannot guarantee the Lean definitions faithfully capture the real mathematical problem.

- **Neither lab’s November claims have passed human peer review yet.**

**Why it matters:** frontier models are now generating dense formal-verification artifacts faster than human mathematicians can audit them. Until independent specialists validate the problem statements and proofs, treat these drops as inspectable conjectures rather than settled breakthroughs.

### Google Research and AllenAI examined where AI assistants still fall short

Two November 25 studies highlight why human framing and scientific norms remain hard bottlenecks for AI assistants:

- **Google Research** open-sourced a multi-agent simulation framework for [verifiable social reasoning](https://research.google/blog/verifiable-social-reasoning-for-llm-assistants). When models hear about interpersonal situations only through a user’s subjective story, they tend to mirror one-sided framing and fail to ask clarifying questions.

- **AllenAI (Ai2)** interviewed 17 scientists across natural, applied, and social sciences on [responsible research agents](https://huggingface.co/blog/allenai/where-scientists-draw-the-line-on-ai-agents). Researchers want clear method provenance, reproducible file trails, hard physical/privacy guardrails, and institutional disclosure rules rather than unchecked autonomy.

**Why it matters:** assistant reliability in real human workflows depends as much on knowing what context is missing—and respecting audit boundaries—as on raw reasoning accuracy.

## Open source and developer tools

### n8n-io/nod (v0.9.7) brings local approval-gated personal automation

[Nod](https://github.com/n8n-io/nod) is an Apache-2.0 open-source personal desktop agent built by the workflow automation company n8n. It runs on your machine with its own isolated browser and computer workspace, connecting to Gmail, Calendar, Slack, Notion, Linear, and Qontext while pausing for approval before acting externally.

![Nod drafting a Slack reply from a pricing sheet and pausing for user approval.](https://raw.githubusercontent.com/n8n-io/nod/main/docs/src/assets/readme/approval.webp)

The [`nod-v0.9.7`](https://github.com/n8n-io/nod/releases/tag/nod-v0.9.7) release restores browser and computer use directly inside main chat, stops re-prompting on actions covered by saved rules, repairs Windows WSL2 startup recovery, and adds Qontext company-knowledge integration.

**Limits and what to do:** Nod is still a **research preview**, and its safety gate relies on model judgment (n8n’s own 240-case test found frontier models blocked all unsafe actions while `Claude Haiku 5.5` let 8 through). Try it with a capable model on low-risk personal tasks first.

### backnotprop/plannotator (v0.29.4) spans linked computers and adds a Ship mode

*Last covered 14 days ago at v0.28.62.* [Plannotator](https://github.com/backnotprop/plannotator) is an Apache-2.0 workspace for reviewing AI agent plans, annotating code diffs, and steering multiple coding agents in one inbox.

![Plannotator guided review interface pairing a change overview with an annotatable diff.](https://raw.githubusercontent.com/backnotprop/plannotator/main/.github/assets/guided-review.webp)

Released November 25, [`v0.29.4`](https://github.com/backnotprop/plannotator/releases/tag/v0.29.4) lets you `@`-mention agents running on other linked machines, routes replies strictly to the named agent, and switches most diagrams from Mermaid to Pele (cutting a 20-diagram plan load from **1,088 ms to 289 ms**). It also introduces an off-by-default **Ship** mode that monitors an open PR and nudges an agent until merge, plus an experimental **Grid** status board.

**What to do:** upgrade if you split agent sessions across a laptop and desktop or review diagram-heavy plans; keep **Ship** disabled on production repos until you test your `gh` merge permissions.

### Lean 4 and differential testing uncovered 17 unreported bugs in Clojure core

*Published Nov 24; surfaced on Hacker News and Lobsters Nov 25.* An independent developer [audited Clojure 1.12.7’s Java core](https://s.conao3.com/blog/2026/e4f733) using Lean 4 bit-vector proofs (`bv_decide`) and 3 million operations of differential testing against `java.util` collections.

- **Core trees held up:** `PersistentHashMap` (HAMT) and persistent vectors matched `HashMap` and `ArrayList` across random sequences and boundary sizes.

- **17 bugs sat in surrounding glue code:** including a bitmask (`0xffe0`) in `gvec.clj`—unchanged since **2010**—that clears upper bits and traps `(reduce + (drop 1 (into (vector-of :long) (range 65505))))` in an infinite loop.

- Other bugs hit HAMT hash-collision removal and unhinted functional-interface Java interop.

**Why it matters:** modeling small bit-twiddling functions in Lean 4 alongside differential testing is becoming a practical, lightweight way for maintainers to catch decade-old edge-case bugs.

## Action radar

### 1. Claude Code v2.1.332 adds MCP skills and a PreSkillShellCommand hook

[Claude Code](https://github.com/anthropics/claude-code/releases/tag/v2.1.332) [`v2.1.332`](https://github.com/anthropics/claude-code/releases/tag/v2.1.332) lets MCP servers expose beta slash skills (`server:skill`) and adds a `PreSkillShellCommand` hook that can block inline shell commands inside a skill as it loads. It also fixes `claude auth login` falsely reporting success when credentials fail to save, adds a 20-second timeout on stalled named pipes (such as locked `.env` secrets managers), prevents terminal freezes when MCP servers or hooks flood output, and accepts `oat02-` OAuth tokens.

**What to do:** if you install third-party skills or MCP servers, configure `PreSkillShellCommand` to audit inline shell execution—but note that older `2.1.331` clients will show a startup dialog if the hook appears in shared settings. Update any proxy log scrubbers matching `oat01-` to also mask `oat02-`.

### 2. OpenClaw v2026.11.10 isolates browser settings and blocks .env credential hijacks

[OpenClaw](https://github.com/openclaw/openclaw/releases/tag/v2026.11.10) [`v2026.11.10`](https://github.com/openclaw/openclaw/releases/tag/v2026.11.10) ([changelog](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.10.md)) ships default-on **Deep Research**, opt-in **Knowledge** vault memory (`plugins.slots.memory = "knowledge"`), and a **Take control** browser toggle for manual CAPTCHAs or logins. It also isolates `chrome://settings` and `chrome://password-manager` tabs completely from the agent, blocks untrusted workspace `.env` files from overriding Azure OpenAI endpoints to steal credentials, confines self-hosted web-tool redirects, and updates LanceDB to `0.41.0` for certificate validation.

**What to do:** upgrade if you run OpenClaw on untrusted repositories or use its built-in browser. If you enable **Knowledge** recall in shadow mode, note that candidate excerpts are sent to your configured Decision provider for scoring.

### 3. Pi v1.6.1 removes showCacheMissNotices and upgrades models.classify()

[Pi](https://github.com/earendil-works/pi/releases/tag/v1.6.1) [`v1.6.1`](https://github.com/earendil-works/pi/releases/tag/v1.6.1) replaces `showCacheMissNotices` (and removes `SettingsManager.getShowCacheMissNotices()` / `setShowCacheMissNotices()`) with four separate `notices.*` settings. It adds `gpt-6-luna-decisions` and Radius decision models to codemode `models.classify()` with `responseId` cost tracking, adds `blockedKind` for extension permission dialogs, and fixes `xhigh` thinking on Gemini 4 Hydrogen/Neon plus GPT-6.2 Codex WebSocket `prefix_mismatch` drops.

**What to do:** extension authors calling the removed `SettingsManager` cache-miss methods must migrate to `getNotices()` / `setNotice()`. Anyone using Gemini 4 Hydrogen/Neon at `xhigh` or GPT-6.2 over Codex WebSockets should upgrade.

## Business opportunities

### 1. Live-traffic parity kit for AI-assisted backend migrations

- **Evidence:** Anthropic’s [Rust migration report](https://www.anthropic.com/research/migrating-api-to-rust) showed AI-ported integration tests passed at 98% while failing ~75% of live requests—and revealed >100 weakened test assertions.

- **Hypothesis:** a privacy-safe shadowing proxy that emits structural diff fingerprints (step, offset, byte delta—never payload text) plus regression gates could serve teams migrating legacy Python/Node services to Rust or Go with coding agents.

- **Validation & risk:** build an open-source HTTP/gRPC checkpoint comparator for one Python-to-Rust endpoint and test it with three engineering teams. Risk: large cloud vendors may bundle traffic-replay tools into existing APM suites.

### 2. Policy and supply-chain scanner for agent skills and MCP servers

- **Evidence:** `1Password`’s breach started in a corporate GitHub account pushing malicious backend code, while `Claude Code v2.1.332` and `OpenClaw v2026.11.10` both shipped emergency hooks to block untrusted skill shell commands and `.env` endpoint redirects.

- **Hypothesis:** a lightweight CI linter and runtime hook pack could scan MCP server manifests, `.env` overrides, and skill inline shell commands across Claude Code, Codex, and OpenClaw workspaces before execution.

- **Validation & risk:** ship a ruleset covering inline skill shell blocks and credential-redirect env vars on 20 popular public skill repos to measure signal-to-noise. Risk: fast-changing agent hook APIs require continuous maintenance.
